# Enunciado — Exercício 1: Introdução ao Git

**Módulo 1 | Tema: Git e GitHub | Tempo sugerido: 15 min**

## Contexto

Este é o primeiro contato com controle de versão. Nesta etapa do curso, o objetivo é criar um repositório, produzir um arquivo de texto e publicá-lo no GitHub, compreendendo o fluxo essencial do Git.

## Desafio

1. Crie um arquivo de texto chamado `minha-bio.txt` dentro da estrutura:

   ```
   modulo1/
   └── aula-git/
       └── sobre-mim/
           └── minha-bio.txt
   ```

2. Escreva uma minibio sobre você (pode ser a mesma que você usou originalmente, ou atualizada).

3. Inicialize o controle de versão no diretório do projeto.

4. Faça o commit do arquivo com uma mensagem descritiva.

5. Conecte o repositório local ao remoto e envie (`push`) seu trabalho para o GitHub.

## O que será avaliado

- Domínio do fluxo: `git init` → `git add` → `git commit` → `git remote add origin` → `git push`
- Estrutura de pastas organizada conforme o padrão do curso
- Mensagem de commit clara e descritiva

## Dica

Confira o estado do repositório com `git status` antes de cada etapa para entender o que o Git está acompanhando.
