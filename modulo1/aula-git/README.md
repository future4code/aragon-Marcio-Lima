# Exercício: git-1

## Objetivo

Iniciar o contato com os fundamentos do Git e GitHub: entender o que é versionamento de código e realizar o primeiro fluxo de criação de um repositório remoto e envio de arquivos locais.

## Conteúdos abordados

- O que é Git e para que serve o controle de versão
- Inicialização de um repositório (`git init`)
- `git status`, `git add` e `git commit`
- Conectar o repositório local ao remoto (`git remote add origin`)
- Envio de arquivos para o GitHub (`git push`)

## O que foi feito

- Criação de uma página de apresentação pessoal com o arquivo `minha-bio.txt`
- Configuração do repositório local e envio do conteúdo para o repositório remoto `aragon-Marcio-Lima`

## Estrutura de arquivos

```
modulo1/
└── aula-git/
    └── sobre-mim/
        └── minha-bio.txt   # minibio criada na aula
```

## Como rodar

Este exercício não possui código executável — trata-se apenas de um arquivo de texto.

Para conferir o conteúdo:

```bash
cat modulo1/aula-git/sobre-mim/minha-bio.txt
```

## Aprendizados

- Primeiro fluxo completo de versionamento: criar arquivo, adicionar, commitar e publicar no GitHub
- Estrutura de organização proposta pelo curso: uma pasta por módulo e uma pasta por aula/exercício
- Importância do versionamento para acompanhar a evolução do código ao longo do curso
